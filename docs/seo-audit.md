### Technical Implementation
- **Canonical Trailing Slash Policy:** The site adheres to `trailingSlash: 'never'`, where root `/` has a trailing slash (`https://onlineinvoicecreator.com/`) and all subpaths terminate without a trailing slash (e.g., `https://onlineinvoicecreator.com/blog`).
- **Internal Linking Directness:** Every internal link on the site links directly to the non-trailing-slash canonical destination. No internal link forces a browser or search crawler through an intermediate 301 hop.
- **Edge Redirection (`public/_redirects`):**
  - Canonical hostname enforcement (`http://` &rarr; `https://`, `www.` &rarr; apex domain).
  - Safety fallbacks for external or legacy requests containing trailing slashes (e.g., `/blog/` &rarr; `/blog` `301`).

## 10. Internationalization & Hreflang Architecture

The application implements a multi-language expansion framework supporting English (primary), Spanish (`es`), and Portuguese (`pt`), with an `x-default` fallback.

### HTML Head Implementation
Every indexable page emits bidirectional hreflang tags:
```html
<link rel="canonical" href="https://onlineinvoicecreator.com/contractor-invoice-template" />
<link rel="alternate" hreflang="en" href="https://onlineinvoicecreator.com/contractor-invoice-template" />
<link rel="alternate" hreflang="es" href="https://onlineinvoicecreator.com/es/contractor-invoice-template" />
<link rel="alternate" hreflang="pt" href="https://onlineinvoicecreator.com/pt/contractor-invoice-template" />
<link rel="alternate" hreflang="x-default" href="https://onlineinvoicecreator.com/contractor-invoice-template" />
```

### Sitemap Synchronization
`dist/sitemap-0.xml` matches the HTML head tags identically via `<xhtml:link>` elements for all 14 indexable routes.

## 11. Issues Fixed & Warnings Rationale

### A. Issues Fixed During Audit
1. **Missing HTML `<head>` Hreflang Alternates:**
   - *Problem:* While `sitemap-0.xml` contained `<xhtml:link rel="alternate">` tags, HTML `<head>` lacked corresponding `<link rel="alternate" hreflang="...">` tags.
   - *Fix:* Enhanced `src/layouts/BaseLayout.astro` to dynamically construct and render `en`, `es`, `pt`, and `x-default` alternate link tags on all indexable pages.
2. **Dynamic Route Normalization:**
   - *Problem:* Trailing slashes could create subtle divergence between canonical tags and hreflang links.
   - *Fix:* Enforced uniform URL normalization logic across `canonicalUrl`, `hreflangEn`, `hreflangEs`, `hreflangPt`, and `hreflangXDefault`.

### B. Warnings & Maintained Design Decisions (Kept Intentionally)
1. **`noindex, nofollow` on `/404.html` and `/style-guide`:**
   - *Rationale:* The 404 page is an error document and must never be indexed by search engines. The style guide is an internal UI design showcase excluded via `robots.txt` and `noindex`.
2. **Inlined Critical CSS (Tailwind CSS v4):**
   - *Rationale:* Inlining compiled utility CSS directly in `<head>` eliminates an external render-blocking network round-trip on mobile Slow 4G connections, enabling **sub-1.4s LCP** and **100/100 Mobile Performance**.
3. **Lazy PDF/Canvas Libraries:**
   - *Rationale:* Heavy document generation libraries (`jspdf`, `html2canvas`, totaling ~580 KB uncompressed) are excluded from the initial critical rendering path. They are loaded exclusively on-demand when the user clicks export buttons.
